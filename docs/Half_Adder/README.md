# Half Adder - Half adder

Adds two 1-bit numbers A and B, producing a sum and a carry. `Sum = A XOR B`, `Carry = A AND B`. The simplest arithmetic building block.

**Interface:** 2 inputs (A, B) / 2 outputs (Sum, Carry).
