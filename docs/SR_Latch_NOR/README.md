# SR Latch NOR - SR latch (NOR)

The classic set-reset latch: two cross-coupled NOR gates. S=1 sets Q high, R=1 resets Q low, S=R=0 holds the last value (S=R=1 is the disallowed input). The fundamental one-bit memory element.

**Interface:** 2 inputs (S, R) / 2 outputs (Q, Qn).
